# 环境检查草稿

## 范围与前提

- 目标环境、负责人、检查时间：待填写。
- OS、运行时、Kubernetes 与中间件版本：待填写。
- 准备只读访问，确认集群上下文和命名空间；本流程不改变配置。

## 检查顺序

| 检查项 | 要记录的证据 | 通过条件 |
| --- | --- | --- |
| 主机资源 | CPU、内存、磁盘容量与使用率 | 满足项目明确的资源基线 |
| 时间与名称解析 | 时间偏差、DNS 解析结果 | 满足组件要求，目标域名解析正确 |
| 存储 | 存储类型、容量、访问方式 | 与工作负载的持久化需求一致 |
| 镜像与依赖 | 版本清单、载荷摘要、仓库连通性 | 所需载荷齐全且可访问 |
| 证书 | 有效期、信任链、域名匹配 | 覆盖上线及维护窗口 |

## 具体命令与判定

按实际版本补充命令、预期结果与失败处理。未补齐前不能作为执行手册验收。

## 退出、回滚与验证

关键项失败时停止交付并记录缺项。只读检查无回滚操作；不得顺手修复环境。记录脱敏证据位置、检查人和复查结果。
