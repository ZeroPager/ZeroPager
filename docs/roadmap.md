# 后续实施顺序

1. 实现统一清单解析与引用校验，验证 profile、ID、路径边界和版本锁定。
2. 先选择一个工具实现配置预览、目标路径映射和原生格式验证。
3. 实现备份、幂等安装与回滚，再逐步接入其他工具。
4. 实现离线载荷校验和环境变量注入，禁止离线模式隐式下载。
5. 将公共规则、技能和记忆接入工具入口，验证确实被读取。
6. 添加跨系统验证和敏感信息检查流程。

通过标准：全新机器可预览并应用指定 profile；再次应用没有额外变更；原配置可恢复；离线 profile 无网络依赖。

## SRE 内容建设优先级

1. 选择一个熟悉的环境，补齐环境检查草稿并记录验证证据。
2. 完成交付验收与一次隔离恢复演练，回写手册缺项。
3. 为一个服务明确 SLI/SLO，建立告警与手册关联。
4. 用真实约束完成一次容量成本评估和架构决策记录。
5. 将反复使用且稳定的操作提炼为独立工具。
