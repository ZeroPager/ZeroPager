# 部署方案检查

1. 阅读现有部署文档、Chart、values 和镜像清单。
2. 核对集群版本、命名空间、存储、资源配额和配置依赖。
3. 检查镜像版本、私有仓库地址注入方式以及离线载荷是否齐全。
4. 检查就绪探针、持久化、升级顺序和回滚条件。
5. 按严重程度列出发现、依据、修复建议及可执行验证命令。

本技能用于审查；实际执行变更需依据用户任务范围。资料不足时明确指出缺项，不能把未验证项标为通过。
